# PeriScan の使い方

[English](usage.md)

PeriScan は、ワールドイーターやトレンチャーを動かす前に**取り除いておくべきブロック**を、範囲を指定するだけでハイライトする mod です。ハイライトは壁越しにも見えるので、地中のチェストや黒曜石も探しに行けます。

Litematica が入っていれば、ペリメータ用の設計図（スケマティック）をまとめて配置することもできます。

- [基本の流れ](#基本の流れ)
- [コマンド](#コマンド)
- [ハイライトされる場所](#ハイライトされる場所)
- [設定](#設定)

- [困ったとき](#困ったとき)

## 基本の流れ

1. ペリメータの範囲を**プロファイル**として登録します。
   ```
   /peri add <x1> <z1> <x2> <z2> <名前>
   ```
2. スキャンを始めます。
   ```
   /peri scan start <名前>
   ```
3. ハイライトされたブロックを取り除きます。取り除いたブロックのハイライトは自動で消えます。
4. 終わったらハイライトを消します。
   ```
   /peri scan clear
   ```

プロファイルはワールド（サーバー）ごとに保存されます。一度ログアウトしても、次に入ったときに `/peri scan reload` を実行すれば、直前にスキャンしていたプロファイルのスキャンを再開できます。

## コマンド

| コマンド | 内容 |
|---|---|
| `/peri add <x1> <z1> <x2> <z2> <名前>` | 範囲をプロファイルとして登録します |
| `/peri remove <名前>` | プロファイルを削除します。そのプロファイルで配置したスケマティックも一緒に消えます |
| `/peri list` | 登録したプロファイルの一覧を表示します |
| `/peri scan start <名前>` | プロファイルの範囲のスキャンを始めます |
| `/peri scan clear` | ハイライトを消してスキャンを止めます（プロファイルは残ります） |
| `/peri scan reload` | 直前にスキャンしていたプロファイルを最初からスキャンし直します |
| `/peri schematic edit <設計図プロファイル>` | 設計図プロファイルの設定画面を開きます。無ければ新しく作ります（[後述](#スケマティックの一括配置)） |
| `/peri schematic place <名前> <設計図プロファイル>` | 設計図プロファイルのスケマティックを、プロファイルの範囲にまとめて配置します |
| `/peri schematic clear <名前>` | プロファイルに配置したスケマティックを消します（プロファイルも設計図プロファイルも残ります） |
| `/peri schematic list` | 設計図プロファイルの一覧を表示します |
| `/peri schematic copy <元> <新>` | 設計図プロファイルを、スケマティックごと別の名前で複製します |
| `/peri schematic remove <設計図プロファイル>` | 設計図プロファイルを削除します。コピーしたスケマティックも一緒に消えます |
| `/peri config` | 設定画面を開きます |

### 範囲の指定

- 座標は**チャンク座標**で指定します。チャンク座標は、ブロック座標を 16 で割って小数点以下を切り捨てた値です（例: X = 100 → 6、X = -1 → -1）。
- 座標を入力するときにタブキーを押すと、今立っているチャンクの座標が候補に出ます。
- 指定した 2 つのチャンクを角とする長方形が、**ペリメータの一番外側**になります。2 つの角はどの順番で指定しても構いません。
- 範囲の最小は 1 チャンク（16 × 16 ブロック）です。
- 範囲の最大は、一辺 512 チャンク（8192 ブロック）です。

### 名前

プロファイル名には英数字と `_` `-` `.` `+` が使えます。スペースは使えません。

### ディメンション

- プロファイルは、`/peri add` を実行したディメンションに結び付きます。スキャンやスケマティックの配置は、そのディメンションにいるときだけできます。
- エンドでは使えません。

## ハイライトされる場所

指定した範囲は、次の 4 つの**ゾーン**に分けてスキャンされます。ゾーンごとに、ハイライトするブロックと色を設定で変えられます。

```
                 北 (-Z)
      +----------------------------+
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TT                        TT|
西    |TT        E E E E         TT|    東
(-X)  |TT                        TT|    (+X)
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      +----------------------------+
                 南 (+Z)

  T = トレンチ（北と南は幅 12、東と西は幅 3。設定で変更可）
  E = イーター領域
```

| ゾーン | 場所 | 初期設定でハイライトされるもの |
|---|---|---|
| トレンチの一つ外側 | 各トレンチの両脇 1 列（範囲の 1 ブロック外側の列と、トレンチのすぐ内側の列） | スカルクセンサー、調律されたスカルクセンサー、溶岩 |
| トレンチの内側 | トレンチ部分（「トレンチの底」がオンの間は、下の 2 段を除く） | ピストンで押せないブロック（下記）、特定の列にある塀やフェンスなど（下記）、落下ブロックの連続（下記） |
| トレンチの底 | トレンチ部分の一番下の 2 段 | なし（掘る前のトレンチでは床全体が光るため、初期設定ではオフ）。オンにすると、空気と液体以外のすべて |
| イーター領域 | トレンチを除いた内側 | 黒曜石、エンダーチェスト、金庫、試練のスポナー、強化深層岩、昆布、水没したブロック |

### 高さの範囲

岩盤の層のすぐ上から、設定の「スキャンする最大Y」（初期値 128）までをスキャンします。

- オーバーワールド: Y = -59 から
- ネザー: Y = 5 から

「トレンチの底」はこの一番下の 2 段です（オーバーワールドなら Y = -59 と -58）。

### トレンチの内側で見ているもの

- **ピストンで押せないブロック**: 黒曜石、泣く黒曜石、リスポーンアンカー、強化深層岩、壊せないブロック、伸びた状態のピストン、それにチェスト・かまど・スポナー・スカルクセンサーなどです。岩盤は地形の一部なので対象外です。
- **特定の列にある、状態が変わるブロック**: 塀・フェンス・板ガラス・鉄格子や、ドア・トラップドア・フェンスゲート・ピストン・ディスペンサー・ホッパー・レッドストーンランプなどレッドストーン信号を受けて状態が変わるブロックです（オブザーバーのように信号を出すだけのブロックは含みません）。これらはトレンチの端から数えて 2, 5, 8, 11 … 列目にあるときだけハイライトされます。それ以外の列ではトレンチャーの邪魔にならないためです。幅 3 のトレンチでは一切ハイライトされません。
- **落下ブロックの連続**: 砂・砂利・コンクリートパウダーなどが、トレンチの長い方向に 10 個以上（設定で変更可）並んでいる所をハイライトします。空気・液体・ピストンで押すと壊れるブロックは数えませんが、連続を途切れさせることもありません。それ以外のブロックがあると連続は途切れます。色は「トレンチの内側」の色になります。

### 範囲が狭い場合

範囲が狭く、ある方向にトレンチを 2 本置けない場合（例: 1 チャンク幅に幅 12 のトレンチ）、その方向のトレンチは 1 本だけになります。1 本になるトレンチは、範囲のうちワールドの中心（X = 0, Z = 0）から遠い側に置かれます。

### まだスキャンされていないチャンク

スキャンは、読み込まれているチャンクから順に行われます。まだ読み込まれていないチャンクは次のように表示されます。

- 画面下に「未ロードチャンクが N 個あります」と表示されます。
- そのチャンクがオレンジ色の大きな箱で表示されます（設定で非表示にできます）。

近づいてチャンクが読み込まれると、自動でスキャンされます。

### ハイライトが消えるタイミング

ハイライトされたブロックが別のブロックに置き換わると、ハイライトは自動で消えます。ほかのプレイヤーが壊した場合も同じです。遠くにいて見えていない間に変わった部分は、近づいてチャンクが読み込まれたときに反映されます。

## 設定

`/peri config` で設定画面を開けます。保存するとすぐに反映され、スキャン中なら新しい設定でスキャンし直します。

### 全般

| 項目 | 内容 | 初期値 |
|---|---|---|
| 南北トレンチの幅 | 北端と南端のトレンチの幅（列数、3 〜 32） | 12 |
| 東西トレンチの幅 | 東端と西端のトレンチの幅（列数、3 〜 32） | 3 |
| スキャンする最大Y | この高さまでスキャンします | 128 |
| ハイライトを表示 | オフにすると、PeriScan が描くもの（ハイライトと未スキャンチャンクの箱）をすべて隠します。スキャンは続きます | オン |
| 未スキャンチャンクをハイライト | まだスキャンしていないチャンクを箱で表示します | オン |
| 未スキャンチャンクの色 | その箱の色 | オレンジ |
| 押すと壊れるブロックを水没判定から除外 | 葉・サンゴ・鍾乳石など、ピストンで押すと壊れるブロックは、水没していてもハイライトしません | オン |
| 水没判定のブラックリスト | 水没していてもハイライトしないブロック | なし |

### ゾーンごとの設定

「トレンチの一つ外側」「トレンチの内側」「トレンチの底」「イーター領域」のそれぞれに、次の設定があります。

| 項目 | 内容 |
|---|---|
| このゾーンを走査する | オフにすると、そのゾーンはスキャンしません。すべてオフにするとスキャンを始められません |
| このゾーンを表示 | オフにすると、そのゾーンのハイライトを隠します。スキャンは続きます |
| ハイライト色 | ハイライトの色（初期値はすべて白） |
| 水没ブロックを含める | 水没したブロック（水の入った階段など）もハイライトします。水そのものはハイライトしません（「トレンチの底」にはありません） |
| ハイライトするブロック | ハイライトするブロックのリスト（「トレンチの底」にはありません） |

ゾーン固有の設定:

- **トレンチの内側**
  - 落下ブロックの連続数しきい値（2 〜 64、初期値 10）
  - state変化ブロック（特定レーンのみ）: 2, 5, 8, 11 … 列目にあるときだけハイライトするブロックのリスト
- **イーター領域**
  - トレンチ範囲を含める: オンにすると、イーター領域がトレンチを含めた範囲全体になります（初期値オフ）

### ブロックの指定方法

ブロックのリストには、次のどれかを 1 行に 1 つずつ書きます。

- ブロック ID: `minecraft:obsidian`
- ブロックタグ（先頭に `#`）: `#minecraft:walls`
- PeriScan の特別な指定:

| 指定 | 一致するブロック |
|---|---|
| `#periscan:immovable` | ピストンで押せないブロック全般（岩盤を除く） |
| `#periscan:connecting` | 塀・フェンス・板ガラス・鉄格子など、隣のブロックとつながって形が変わるブロック |
| `#periscan:redstone_reactive` | ドア・トラップドア・フェンスゲート・銅の電球・ピストン・レッドストーンダスト/トーチ/ランプ・ディスペンサー・ホッパーなど、レッドストーン信号を受けて状態が変わるブロック（ボタンやレバーなど信号を出すだけのブロックは含まない） |

存在しない ID など、書き間違えた項目は無視されます。スキャンを始めたときに、チャットに「不正なconfigエントリを無視しました」と表示されます。

## キー

「設定 → 操作設定 → キー割り当て」の「PeriScan」に、次のキーが追加されます。最初はどれもキーが割り当てられていないので、使いたいものに割り当ててください。

| キー | 内容 |
|---|---|
| 設定を開く | 設定画面を開きます（`/peri config` と同じ） |
| ハイライトの表示切替 | PeriScan が描くものをすべて隠す／表示します。設定の「ハイライトを表示」と同じです |
| 再スキャン | `/peri scan reload` と同じ |
| スキャンを消去 | `/peri scan clear` と同じ |
| 「トレンチの一つ外側」の表示切替 | そのゾーンのハイライトを隠す／表示します。設定の「このゾーンを表示」と同じです |
| 「トレンチの内側」の表示切替 | 同上。落下ブロックの連続も一緒に隠れます |
| 「トレンチの底」の表示切替 | 同上 |
| 「イーター領域」の表示切替 | 同上 |

- 隠してもスキャンは止まらないので、表示に戻したときには最新の状態になっています。
- 隠した状態はゲームを再起動しても残ります。表示に戻すまで隠れたままです。
- 「このゾーンを走査する」がオフのゾーンには表示するものがないので、キーを押しても「有効になっていません」と表示されるだけです。

## スケマティックの一括配置

ペリメータを作るときは、毎回同じ設計図を同じ位置関係で置くことになります。**設計図プロファイル**に「どのスケマティックをどこに置くか」を覚えさせておくと、`/peri schematic place` でプロファイルの範囲に合わせて Litematica にまとめて配置できます。

**Litematica が必要です。** 入っていなくても、ほかの機能は使えます。

設計図プロファイルは、`/peri add` で作るプロファイルと違い、すべてのワールド・サーバーで共通です。

### 設計図プロファイルの作りかた

1. 設定画面を開きます。名前は自由に付けられ、まだ無いプロファイルは保存したときに作られます。
   ```
   /peri schematic edit <設計図プロファイル>
   ```
2. 「設計図を取り込む」に、使うファイルを追加します。候補には Litematica のスケマティックフォルダ（通常は `.minecraft/schematics`）にある `.litematic` ファイルが出ます。文字を入力すると候補が絞り込まれるので、クリックして選んでください。
3. 「変更を保存」を押します。取り込んだスケマティックごとに設定欄が現れます。
4. それぞれの設定欄で、設置する角と原点の高さを選び、もう一度保存します。

- ファイルは `config/periscan/schematics/<設計図プロファイル>/` に**コピー**されます。取り込んだ後は、元のファイルを移動・改名・削除しても構いません。
- 元のファイルを作り直しても、自動では反映されません。もう一度取り込んでください。同じ名前のファイルはコピーだけが置き換わり、設定は残ります。
- 同じ名前のファイルは、別のフォルダにあっても 1 回の保存では取り込めません。どれも取り込まれず、メッセージに一覧が出ます。片方の名前を変えるか、1 つずつ保存して取り込んでください（後から取り込んだほうで置き換わります）。
- 一番上の「originのYの初期値」は、新しく取り込むスケマティックが最初に持つ原点の高さです。取り込む前に設定してください（ネザー用のプロファイルなら 5 など）。
- スケマティックをプロファイルから外すには、設定欄の「プロファイルから外す」をオンにして保存します。コピーも削除されます。

オーバーワールド用のプロファイルからネザー用を作るときのように、少しだけ違うものが欲しい場合は、`/peri schematic copy <元> <新>` で複製してから、高さや角を変えてください。

### スケマティックの保存のしかた

どのファイルも、次のルールで保存してください。

- 原点を、ペリメータの**北西の角のブロック**に合わせる
- 中身は、原点から東（+X）と南（+Z）の方向に広がる形にする

複数の辺で使い回せる部分は 1 つだけ保存し、複数の角に設置します。

### 配置のされかた

角は X 側と Z 側の符号で表します。`+-` は +X / -Z の角です。

| 角 | 置かれる場所 |
|---|---|
| `--` | 北西の角に、保存したとおり |
| `+-` | 北東の角に、東西反転 |
| `-+` | 南西の角に、南北反転 |
| `++` | 南東の角に、180° 回転 |

- 原点の高さはスケマティックごとに設定します。新しいスケマティックは、プロファイルの「originのYの初期値」から始まります（変更していなければ -59 で、オーバーワールドの岩盤の層のすぐ上です。ネザーでは 5 にしてください）。
- 角を 1 つも選んでいないスケマティックは配置されません。
- 反転すると回路の左右も入れ替わります。左右対称でない回路は、反転すると動かないことがあります。
- 180° 回転すると装置の向きが逆になります。向きが決まっているもの（動き出す向きが決まっているトレンチャーなど）は、`++` ではなく `+-` か `-+` を使ってください。

### 配置されたもの

- Litematica の配置一覧に `peri/<プロファイル名>/…` という名前で追加されます。誤って動かさないよう、位置はロックされています。
- 同じプロファイルでもう一度実行すると、前に配置したものは置き換えられます。
- 読み込めないファイルが 1 つでもあると、何も配置されません。
- `/peri schematic clear <名前>` で、プロファイルの配置を消せます。`/peri remove` でプロファイルを削除したときも消えます。
- 配置は設計図プロファイル内のコピーを参照し続けます。スケマティックを外したり設計図プロファイルを削除したりすると、ほかのワールドでそこから作った配置は読み込めなくなります。

## 困ったとき

| 表示・症状 | 対処 |
|---|---|
| 「すべてのゾーンが無効です」 | `/peri config` で、少なくとも 1 つのゾーンの「このゾーンを走査する」をオンにしてください |
| 「profile「…」は … のprofileです」 | プロファイルを作ったディメンションに移動してから実行してください |
| 「未ロードチャンクが N 個あります」 | オレンジの箱の場所に近づくと、そのチャンクがスキャンされます |
| 「保存されたprofileがあります」 | そのディメンションで `/peri scan reload` を実行すると、スキャンを再開します |
| 「litematicaが入っていない(または非対応バージョンの)ため…」 | Litematica を入れるか、Minecraft のバージョンに合った Litematica に更新してください |
| 「設計図プロファイル「…」はありません」 | `/peri schematic edit <設計図プロファイル>` で作るか、`/peri schematic list` で名前を確認してください |
| 「… には設置するものがありません」 | `/peri schematic edit <設計図プロファイル>` でスケマティックを取り込み、角を 1 つ以上選んでください |
| 「取り込みに失敗」 | ファイルが Litematica のスケマティックフォルダにあり、名前が `.litematic` で終わっているか確認してください |
| 「… の読み込みに失敗しました」 | そのファイルが壊れていないか、Litematica で開けるか確認してください |
| スキャン中なのにハイライトが出ない | 設定の全般の「ハイライトを表示」と、各ゾーンの「このゾーンを表示」を確認してください。キーでオフにしたままかもしれません |
| ゾーンのキーを押すと「…は有効になっていません」 | 設定で、そのゾーンの「このゾーンを走査する」をオンにしてください |
| シェーダー使用中にハイライトが見えない | Iris を最新版に更新してください |
