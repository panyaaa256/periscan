# PeriScan の使い方

[English](usage.md)

PeriScanは、World Eaterやtrencherの動作を妨げるブロックを、指定した範囲の中から探してハイライトするmodです。ハイライトはブロックを貫通して見えるので、地中のチェストや黒曜石も事前に取り除けます。Litematicaが入っていれば、よく使う設計図を範囲に合わせてまとめて配置することもできます。

## まず使ってみる

1. 露天掘りの範囲を、名前を付けてプロファイルとして登録します。
   ```
   /peri add <x1> <z1> <x2> <z2> <名前>
   ```
2. そのプロファイルの範囲をスキャンします。
   ```
   /peri scan start <名前>
   ```
3. ハイライトされたブロックを取り除きます。取り除いたブロックのハイライトは自動で消えます。

## 範囲を登録する

範囲は`/peri add <x1> <z1> <x2> <z2> <名前>`で登録します。登録した範囲をプロファイルと呼びます。

### 座標の指定

指定する座標は、チャンク座標です。今いるチャンクの座標は、F3のデバッグ画面で確認できます。座標を入力しているときにTabキーを押すと、今立っているチャンクの座標が候補に出ます。

指定するのは、露天掘りの範囲の対角にある2つのチャンクです。どちらを先に書いてもかまいません。範囲は最小で1チャンク（16×16ブロック）、最大で一辺512チャンク（8192ブロック）の正方形まで指定できます。

### 名前

プロファイル名に使えるのは、英数字と`_` `-` `.` `+`です。スペースは使えません。

### ディメンション

プロファイルは、`/peri add`を実行したディメンションに結び付きます。スキャンと設計図の配置は、そのディメンションにいるときだけ実行できます。エンドではPeriScanを使えません。

### プロファイルの保存先と管理

プロファイルは、ワールドごと（マルチプレイならサーバーごと）に保存されます。登録したプロファイルの一覧を見るコマンドは`/peri list`です。

`/peri remove <名前>`でプロファイルを削除すると、そのプロファイルに配置した設計図も一緒に消えます。

## スキャンする

### 開始・停止・やり直し

`/peri scan start <名前>`で、プロファイルの範囲のスキャンを始めます。`/peri scan clear`は、ハイライトを消してスキャンを止めるコマンドです。プロファイルは消えません。

`/peri scan reload`は、直前にスキャンしていたプロファイルを最初からスキャンし直すコマンドです。ログアウトしたあとも、このコマンドで同じプロファイルのスキャンを再開できます。

### スキャンの進み方

チャンクのスキャンの進み方は、サーバーにPeriScanが入っているかどうかで変わります。シングルプレイでは、ゲーム内部のサーバーにもPeriScanが入ります。そのため、シングルプレイでは常にサーバーに入っているときの進み方です。

#### サーバーにPeriScanが入っているとき（Minecraft 1.21.9以降）

範囲内のすべてのチャンクを、サーバーがスキャンします。どのプレイヤーも読み込んでいないチャンクも対象です。スキャンが終わるまでは、画面下に「サーバーで走査中です - 残り N チャンク」と表示されます。まだスキャンしていないチャンクの場所には、オレンジ色の大きな箱が出ます。この箱を消したいときは、設定の「未スキャンチャンクをハイライト」をオフにしてください。

落下ブロックの連続は、範囲全体のスキャンが終わってからハイライトされます。

まだ生成されていないチャンクはスキャンしません。スキャンが終わると、そのチャンクの数がチャットに表示されます。近くまで行くなどしてチャンクを生成してから、`/peri scan reload`を実行してください。

#### サーバーにPeriScanが入っていないとき

チャンクをスキャンするのは、自分のゲームでそのチャンクが読み込まれた時点です。まだ読み込まれていないチャンクがある間は、画面下に「未ロードチャンクが N 個あります」と表示されます。そのチャンクの場所にはオレンジ色の大きな箱が出ます。箱を消す方法は上と同じです。

チャンクは、近づいて読み込まれた時点でスキャンされます。

### ブロックが変わったとき

ブロックが変わると、ハイライトもすぐに変わります。ほかのプレイヤーが変えたブロックも同じです。

- ハイライトされたブロックが別のブロックに置き換わると、そのハイライトは消えます。
- 溶岩と水でできた黒曜石のように、ハイライトすべきブロックが新しく現れると、すぐにハイライトされます。
- 落下ブロックの連続は、その一部が壊されたときや、落ちてきた砂や砂利が着地したときに更新されます。

サーバーにPeriScanが入っていれば、範囲内のどこで起きた変化も反映されます。自分が読み込んでいないチャンクの変化も対象です。ただし、自分で壊したり置いたりしたブロックは、サーバーを経由するぶん反映が少し遅れます。

サーバーにPeriScanが入っていなければ、遠くにいて見えない間に変わった部分が反映されるのは、近づいてチャンクが読み込まれたときです。

## ハイライトされるブロック

### 4つのゾーン

登録した範囲は、次の4つのゾーンに分けてスキャンされます。ハイライトするブロックと色は、ゾーンごとに設定で変えられます。

```
                 北 (-Z)
      +----------------------------+
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TT                        TT|
西    |TT        E E E E         TT|    東
(-X)  |TT                        TT|    (+X)
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      +----------------------------+
                 南 (+Z)

  T = トレンチ（北と南は幅 12、東と西は幅 3。設定で変更可）
  E = イーター領域
```

| ゾーン | 場所 | 初期設定でハイライトされるもの |
|---|---|---|
| トレンチの一ブロック外側 | 各トレンチの両脇の1列ずつ。範囲の1ブロック外側の列と、トレンチのすぐ内側の列です | スカルクセンサー、調律されたスカルクセンサー、溶岩 |
| トレンチの内側 | トレンチ部分。「トレンチの底」がオンの間は、下の2段を除きます | ピストンで押せないブロック、特定の列にある塀やフェンスなど、落下ブロックの連続（詳しくは下の節） |
| トレンチの底 | トレンチ部分の一番下の2段 | オンにすると、空気と液体以外のすべて |
| イーター領域 | トレンチを除いた内側 | 黒曜石、エンダーチェスト、金庫、試練のスポナー、強化深層岩、昆布、水没したブロック |

### スキャンする高さ

スキャンするのは、岩盤の層のすぐ上から、設定の「スキャンする最大Y」（初期値128）までです。下端はディメンションによって違い、オーバーワールドではY=-59、ネザーではY=5から始まります。

「トレンチの底」は、この範囲の一番下の2段です。オーバーワールドなら、Y=-59と-58にあたります。

### トレンチの内側で見るもの

「トレンチの内側」では、次の3種類をハイライトします。

#### ピストンで押せないブロック

黒曜石、泣く黒曜石、リスポーンアンカー、強化深層岩、壊せないブロック、伸びた状態のピストンです。チェスト、かまど、スポナー、スカルクセンサーなども含みます。岩盤は地形の一部なので対象外です。

#### 特定の列にある、状態が変わるブロック

塀、フェンス、板ガラス、鉄格子のほか、レッドストーン信号を受けて状態が変わるブロックです。ドア、トラップドア、フェンスゲート、ピストン、レッドストーンランプなどがこれにあたります。ハイライトするのは、トレンチの端から数えて2、5、8、11…列目にあるときだけです。幅3のトレンチでは、どの列でもハイライトしません。

#### 落下ブロックの連続

砂、砂利、コンクリートパウダーなどが、トレンチの長い方向に10個以上並んでいる所です。個数は設定で変えられます。空気、液体、ピストンで押すと壊れるブロックは個数に数えませんが、連続を途切れさせることもありません。

## ハイライトの表示を切り替える

ハイライトは、スキャンを止めずに全体またはゾーンごとに隠せます。隠している間もスキャンは続くため、表示に戻したときのハイライトは最新の状態です。

切り替えは、設定画面の「ハイライトを表示」「このゾーンを表示」か、次のキーで行います。キーは「設定 → 操作設定 → キー割り当て」のPeriScanカテゴリにあります。最初はどのキーも割り当てられていないので、使うものに割り当ててください。

| キー | 内容 |
|---|---|
| 設定を開く | 設定画面を開きます（`/peri config`と同じ） |
| ハイライトの表示切替 | PeriScanが描くものをすべて隠すか、表示に戻します。設定の「ハイライトを表示」と同じです |
| 再スキャン | `/peri scan reload`と同じです |
| スキャンを消去 | `/peri scan clear`と同じです |
| 「トレンチの一ブロック外側」の表示切替 | そのゾーンのハイライトを隠すか、表示に戻します。設定の「このゾーンを表示」と同じです |
| 「トレンチの内側」の表示切替 | 上と同じです。落下ブロックの連続も一緒に隠れます |
| 「トレンチの底」の表示切替 | 上と同じです |
| 「イーター領域」の表示切替 | 上と同じです |

隠した状態は、ゲームを再起動しても残ります。表示に戻すまでは隠れたままです。

「このゾーンを走査する」がオフのゾーンには、ハイライトするものがありません。そのゾーンのキーを押しても、「有効になっていません」と表示されるだけです。

## 設定

設定画面を開くコマンドは`/peri config`です。Mod Menuが入っていれば、Mod MenuのPeriScanの設定ボタンからも開けます。設定が反映されるのは、保存した時点です。スキャン中なら、新しい設定でスキャンし直します。

設定画面を開くにはYACLが必要です。Minecraft 1.21.9以降では、YACLがなくても初期設定のままPeriScanを使えます。

### 全般

| 項目 | 内容 | 初期値 |
|---|---|---|
| 南北トレンチの幅 | 北端と南端のトレンチの幅を列数で指定します（3〜32） | 12 |
| 東西トレンチの幅 | 東端と西端のトレンチの幅を列数で指定します（3〜32） | 3 |
| スキャンする最大Y | スキャンする高さの上限のY座標です | 128 |
| ハイライトを表示 | オフにすると、PeriScanが描くものをすべて隠します。ハイライトも未スキャンチャンクの箱も隠れますが、スキャンは続きます | オン |
| 未スキャンチャンクをハイライト | まだスキャンしていないチャンクを箱で表示します | オン |
| 未スキャンチャンクの色 | 上の箱の色です | オレンジ |
| 押すと壊れるブロックを水没判定から除外 | 葉、サンゴ、鍾乳石など、ピストンで押すと壊れるブロックは、水没していてもハイライトしません | オン |
| 水没判定のブラックリスト | 水没していてもハイライトしないブロックのリストです | なし |

### ゾーンごとの設定

4つのゾーンには、それぞれ次の設定があります。

| 項目 | 内容 |
|---|---|
| このゾーンを走査する | オフにすると、そのゾーンはスキャンしません。すべてのゾーンをオフにすると、スキャンは実行されません |
| このゾーンを表示 | オフにすると、そのゾーンのハイライトを隠します。スキャンは続きます |
| ハイライト色 | ハイライトの色です。初期値はどのゾーンも白です |
| 水没ブロックを含める | 水の入った階段のような、水没したブロックもハイライトします |
| ハイライトするブロック | ハイライトするブロックのリストです。「トレンチの底」にはこの項目がありません |

次の設定は、表のゾーンにだけある項目です。

| ゾーン | 項目 | 内容 |
|---|---|---|
| トレンチの内側 | 落下ブロックの連続数しきい値 | 落下ブロックが何個並んだらハイライトするかを決めます（2〜64、初期値10） |
| トレンチの内側 | state変化ブロック(特定レーンのみ) | 2、5、8、11…列目にあるときだけハイライトするブロックのリストです |
| イーター領域 | トレンチ範囲を含める | オンにすると、イーター領域がトレンチも含めた範囲全体になります（初期値はオフ） |

### ブロックの指定方法

ブロックのリストには、1行に1つずつ次のどれかを書きます。

- ブロックID（例: `minecraft:obsidian`）
- 先頭に`#`を付けたブロックタグ（例: `#minecraft:walls`）
- PeriScanの特殊なタグ（下の表）

| 特殊なタグ | 一致するブロック |
|---|---|
| `#periscan:immovable` | ピストンで押せないブロック全般です。岩盤は含みません |
| `#periscan:connecting` | 塀、フェンス、板ガラス、鉄格子など、隣のブロックとつながって形が変わるブロックです |
| `#periscan:redstone_reactive` | ドア、トラップドア、フェンスゲート、銅の電球、ピストン、レッドストーンダスト・トーチ・ランプ、ディスペンサー、ホッパーなど、レッドストーン信号を受けて状態が変わるブロックです。ボタンやレバーのように信号を出すだけのブロックは含みません |

入力している間は、ブロックIDとタグの候補が出ます。ワールドにあるタグが候補に出るのは、ワールドに入っている間に設定画面を開いたときだけです。候補にないものも入力できます。

存在しないIDなどの書き間違いは無視されます。無視された項目は画面右上に一覧で出ます。スキャンを始めたときにチャットに出る「不正なconfigエントリを無視しました」も、この書き間違いの警告です。

## 設計図をまとめて配置する

露天掘りを作るときは、毎回同じ設計図を同じ位置関係で置くことになります。どの設計図をどこに置くかを設計図プロファイルに登録しておくと、`/peri schematic place`でまとめて配置できます。配置はプロファイルの範囲に合わせてLitematicaで行います。

この機能にはLitematicaが必要です。Litematicaが入っていなくても、ほかの機能は使えます。

設計図プロファイルは、すべてのワールドとサーバーで共通です。`/peri add`で作るプロファイルがワールドごとに保存されるのとは扱いが違います。

### 設計図の保存のしかた

どの設計図ファイルも、次の形で保存してください。

- 原点を、露天掘りの北西の角のブロックに合わせます。
- 中身は、原点から東（+X）と南（+Z）へ広がる形にします。

いくつかの辺で使い回せる部分は1つだけ保存し、それを複数の角に設置します。

### 設計図プロファイルの作り方

1. 設計図プロファイルを作り、その設定画面を開きます。名前は自由に付けられます。新しく作るときは`create`、作ったものを開き直すときは`edit`を使います。
   ```
   /peri schematic create <設計図プロファイル>
   /peri schematic edit <設計図プロファイル>
   ```
2. 「設計図を取り込む」に、使うファイルを追加します。候補には、Litematicaの設計図フォルダ（通常は`.minecraft/schematics`）にある`.litematic`ファイルが出ます。文字を入力すると候補が絞り込まれるので、クリックして選んでください。
3. 「変更を保存」を押します。取り込んだ設計図ごとに設定欄が現れます。
4. それぞれの設定欄で、設置する角と原点の高さを選びます。選び終えたら、もう一度保存します。

取り込んだファイルは、`config/periscan/schematics/<設計図プロファイル>/`にコピーされます。取り込んだあとは、元のファイルを移動しても、名前を変えても、削除してもかまいません。

元のファイルを作り直しても、コピーには自動で反映されません。もう一度取り込んでください。同じ名前のファイルを取り込むと、コピーだけが置き換わり、設定は残ります。

同じ名前のファイルは、別々のフォルダにあっても1回の保存では取り込めません。このときはどのファイルも取り込まれず、メッセージに一覧が出ます。片方の名前を変えるか、1つずつ保存して取り込んでください。1つずつ取り込んだ場合は、あとから取り込んだほうで置き換わります。

設定画面の一番上にある「originのYの初期値」は、新しく取り込む設計図が最初に持つ原点の高さです。設計図を取り込む前に設定してください。ネザー用のプロファイルなら、たとえば5です。

設計図をプロファイルから外すには、その設定欄の「プロファイルから外す」をオンにして保存します。プロファイル内のコピーも削除されます。

オーバーワールド用のプロファイルからネザー用を作るときのように、少し変えるだけで済む場合があります。そのときは`/peri schematic copy <元> <新>`で複製してから、高さや角を変えてください。

### 角ごとの置かれ方

角は、X側とZ側の符号の組み合わせで表します。たとえば`+-`は、+X側かつ-Z側の角です。

| 角 | 置かれる場所と向き |
|---|---|
| `--` | 北西の角に、保存したとおりの向きで |
| `+-` | 北東の角に、東西を反転して |
| `-+` | 南西の角に、南北を反転して |
| `++` | 南東の角に、180°回転して |

反転すると、回路の左右も入れ替わります。左右対称でない回路は、反転すると動かないことがあります。180°回転なら、装置の向きは逆です。設定欄の「保存した向きを保つ」をオンにすると、配置するときに反転も回転もしません。

原点の高さは設計図ごとに設定できます。新しく取り込んだ設計図の原点の高さは、プロファイルの「originのYの初期値」になります。その既定値は-59です。

角を1つも選んでいない設計図は配置されません。

### 配置したあと

配置したものは、Litematicaの配置一覧に`peri/<プロファイル名>/…`という名前で追加されます。位置は、誤って動かさないようにロックした状態です。

同じプロファイルでもう一度配置すると、前に配置したものは置き換わります。読み込めないファイルが1つでもあると、何も配置されません。

配置を消すコマンドは`/peri schematic clear <名前>`です。`/peri remove`でプロファイルを削除したときも消えます。

配置したものは、設計図プロファイルの中のコピーを参照し続けます。そのため、設計図を外したり設計図プロファイルを削除したりすると、そこから作った配置はほかのワールドで読み込めなくなります。

## コマンド一覧

| コマンド | 内容 |
|---|---|
| `/peri add <x1> <z1> <x2> <z2> <名前>` | 範囲をプロファイルとして登録します |
| `/peri remove <名前>` | プロファイルを削除します。そのプロファイルに配置した設計図も消えます |
| `/peri list` | 登録したプロファイルの一覧を表示します |
| `/peri scan start <名前>` | プロファイルの範囲のスキャンを始めます |
| `/peri scan clear` | ハイライトを消してスキャンを止めます。プロファイルは残ります |
| `/peri scan reload` | 直前にスキャンしていたプロファイルを最初からスキャンし直します |
| `/peri schematic create <設計図プロファイル>` | 設計図プロファイルを新しく作ります |
| `/peri schematic edit <設計図プロファイル>` | 設計図プロファイルの設定画面を開きます |
| `/peri schematic place <名前> <設計図プロファイル>` | 設計図プロファイルの設計図を、プロファイルの範囲にまとめて配置します |
| `/peri schematic clear <名前>` | プロファイルに配置した設計図を消します。プロファイルも設計図プロファイルも残ります |
| `/peri schematic list` | 設計図プロファイルの一覧を表示します |
| `/peri schematic copy <元> <新>` | 設計図プロファイルを、設計図ごと別の名前で複製します |
| `/peri schematic remove <設計図プロファイル>` | 設計図プロファイルを削除します。コピーした設計図も消えます |
| `/peri config` | 設定画面を開きます |

## 困ったとき

| 表示・症状 | 対処 |
|---|---|
| 「すべてのゾーンが無効です」 | `/peri config`で、少なくとも1つのゾーンの「このゾーンを走査する」をオンにしてください |
| 「profile「…」は … のprofileです」 | プロファイルを作ったディメンションに移動してから実行してください |
| 「保存されたprofileがあります」 | そのディメンションで`/peri scan reload`を実行すると、スキャンを再開します |
| 「サーバーで走査中です - 残り N チャンク」 | そのまま待ってください。残りのチャンクはサーバーがスキャンします |
| 「範囲内の N チャンクは未生成のため走査していません」 | 近くまで行くなどしてそのチャンクを生成してから、`/peri scan reload`を実行してください |
| 「N チャンクはサーバーのセーブデータを読み込めなかったため…」 | どのチャンクがなぜ読めなかったかは、サーバーのログにあります。そのチャンクのセーブデータが破損している可能性があります |
| 「未ロードチャンクが N 個あります」 | オレンジの箱の場所に近づくと、そのチャンクがスキャンされます。サーバーにPeriScanが入っていないときの表示です |
| スキャン中なのにハイライトが出ない | 設定の「ハイライトを表示」と、各ゾーンの「このゾーンを表示」を確認してください。キーで隠したままの可能性があります |
| ゾーンのキーを押すと「…は有効になっていません」 | 設定で、そのゾーンの「このゾーンを走査する」をオンにしてください |
| 「YetAnotherConfigLib (YACL) が入っていないため、設定画面を開けません」 | 設定画面を使うにはYACLを入れてください。入れるまでは初期設定のまま動きます |
| 「litematicaが入っていない(または非対応バージョンの)ため…」 | Litematicaを入れるか、Minecraftのバージョンに合ったLitematicaに更新してください |
| 「設計図プロファイル「…」はありません」 | `/peri schematic create <設計図プロファイル>`で作るか、`/peri schematic list`で名前を確認してください |
| 「… には設置するものがありません」 | `/peri schematic edit`か`create`で設計図を取り込み、角を1つ以上選んでください |
| 「取り込みに失敗」 | ファイルがLitematicaの設計図フォルダにあり、名前が`.litematic`で終わっているか確認してください |
| 「… の読み込みに失敗しました」 | そのファイルが破損していないか、Litematicaで開けるか確認してください |
| シェーダー使用中にハイライトが見えない | Irisを最新版に更新してください |
