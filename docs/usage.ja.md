# PeriScan の使い方

[English](usage.md)

PeriScan は、指定範囲内における、World Eater や trencher が正常に動くのを妨げるブロックをハイライトする mod です。ハイライトはブロックを貫通して描画されるので、地中のチェストや黒曜石も事前に取り除くことができます。

Litematica を使用して、よく使う設計図を一括配置できます。

- [基本の流れ](#基本の流れ)
- [コマンド](#コマンド)
- [ハイライトされる場所](#ハイライトされる場所)
- [設定](#設定)
- [キー](#キー)
- [設計図の一括配置](#設計図の一括配置)
- [困ったとき](#困ったとき)

## 基本の流れ

1. 露天掘りの範囲をプロファイルとして登録します。
   ```
   /peri add <x1> <z1> <x2> <z2> <名前>
   ```
2. スキャンを始めます。
   ```
   /peri scan start <名前>
   ```
3. ハイライトされたブロックを取り除きます。取り除いたブロックのハイライトは自動で消えます。


プロファイルの保存先はワールド（サーバー）ごとです。一度ログアウトしても、`/peri scan reload` を実行することで、直前にスキャンしていたプロファイルのスキャンを再実行できます。

## コマンド

| コマンド | 内容 |
|---|---|
| `/peri add <x1> <z1> <x2> <z2> <名前>` | 範囲をプロファイルとして登録します |
| `/peri remove <名前>` | プロファイルを削除します。そのプロファイルで配置した設計図も一緒に消えます |
| `/peri list` | 登録したプロファイルの一覧を表示します |
| `/peri scan start <名前>` | プロファイルの範囲のスキャンを始めます |
| `/peri scan clear` | ハイライトを消してスキャンを止めます（プロファイルは残ります） |
| `/peri scan reload` | 直前にスキャンしていたプロファイルを最初からスキャンし直します |
| `/peri schematic edit <設計図プロファイル>` | 設計図プロファイルの設定画面を開きます。（[後述](#設計図の一括配置)） |
| `/peri schematic create <設計図プロファイル>` | 設計図プロファイルを新規作成します。（[後述](#設計図の一括配置)） |
| `/peri schematic place <名前> <設計図プロファイル>` | 設計図プロファイルの設計図を、プロファイルの範囲にまとめて配置します |
| `/peri schematic clear <名前>` | プロファイルに配置した設計図を消します（プロファイルも設計図プロファイルも残ります） |
| `/peri schematic list` | 設計図プロファイルの一覧を表示します |
| `/peri schematic copy <元> <新>` | 設計図プロファイルを、設計図ごと別の名前で複製します |
| `/peri schematic remove <設計図プロファイル>` | 設計図プロファイルを削除します。コピーした設計図も一緒に消えます |
| `/peri config` | 設定画面を開きます |

### 範囲の指定

- 座標は**チャンク座標**で指定します。チャンク座標は F3 によるデバッグ画面から確認ができます。
- 座標を入力するときにタブキーを押すと、今立っているチャンクの座標が候補に出ます。
- 露天掘り範囲の対角にある、2 つのチャンクを指定してください。どの順番で指定しても構いません。
- 最小範囲は、1 チャンク（16 × 16 ブロック）です。
- 最大範囲は、一辺 512 チャンク（8192 ブロック）の正方形です。

### 名前

プロファイル名には英数字と `_` `-` `.` `+` が使えます。スペースは使えません。

### ディメンション

- プロファイルは、`/peri add` を実行したディメンションに結び付きます。紐づけられたディメンション以外にいるときは、スキャン及び設計図の配置はできません。
- エンドでは使えません。

## ハイライトされる場所

指定した範囲は、次の 4 つの**ゾーン**に分かれてスキャンされます。ゾーンごとに、ハイライトするブロックと色を設定で変えられます。

```
                 北 (-Z)
      +----------------------------+
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TT                        TT|
西    |TT        E E E E         TT|    東
(-X)  |TT                        TT|    (+X)
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      |TTTTTTTTTTTTTTTTTTTTTTTTTTTT|
      +----------------------------+
                 南 (+Z)

  T = トレンチ（北と南は幅 12、東と西は幅 3。設定で変更可）
  E = イーター領域
```

| ゾーン | 場所 | 初期設定でハイライトされるもの |
|---|---|---|
| トレンチの一ブロック外側 | 各トレンチの両脇 1 列（範囲の 1 ブロック外側の列と、トレンチのすぐ内側の列） | スカルクセンサー、調律されたスカルクセンサー、溶岩 |
| トレンチの内側 | トレンチ部分（「トレンチの底」がオンの間は、下の 2 段を除く） | ピストンで押せないブロック（下記）、特定の列にある塀やフェンスなど（下記）、落下ブロックの連続（下記） |
| トレンチの底 | トレンチ部分の一番下の 2 段 | オンにすると、空気と液体以外のすべて |
| イーター領域 | トレンチを除いた内側 | 黒曜石、エンダーチェスト、金庫、試練のスポナー、強化深層岩、昆布、水没したブロック |

### 高さの範囲

スキャンする高さは、岩盤の層のすぐ上から、設定の「スキャンする最大 Y」（初期値 128）までです。

- オーバーワールド: Y = -59 から
- ネザー: Y = 5 から

「トレンチの底」はこの一番下の 2 段です（オーバーワールドなら Y = -59 と -58）。

### トレンチの内側でハイライトされるブロック

- **ピストンで押せないブロック**: 黒曜石、泣く黒曜石、リスポーンアンカー、強化深層岩、壊せないブロック、伸びた状態のピストン、それにチェスト・かまど・スポナー・スカルクセンサーなどです。岩盤は地形の一部なので対象外です。
- **特定の列にある、状態が変わるブロック**: 塀・フェンス・板ガラス・鉄格子や、ドア・トラップドア・フェンスゲート・ピストン・レッドストーンランプなどレッドストーン信号を受けて状態が変わるブロックです。これらがハイライトされるのは、トレンチの端から数えて 2, 5, 8, 11 … 列目にあるときだけです。幅 3 のトレンチでは一切ハイライトされません。
- **落下ブロックの連続**: ハイライトの対象は、砂・砂利・コンクリートパウダーなどが、トレンチの長い方向に 10 個以上（設定で変更可）並んでいる所です。空気・液体・ピストンで押すと壊れるブロックは、カウントはされませんが、連続を途切れさせることもありません。

### まだスキャンされていないチャンク

スキャンは、チャンクが読み込まれたら即座に実行されます。まだ読み込まれていないチャンクの表示は次のとおりです。

- 画面下の「未ロードチャンクが N 個あります」という表示
- そのチャンクの場所に出る、オレンジ色の大きな箱（設定で非表示にできます）

近づいてチャンクを読み込むことでスキャンされます。

### ブロックが変わったとき

ブロックの変化は、ほかのプレイヤーによるものも含めて、すぐにハイライトに反映されます。ハイライトされたブロックが別のブロックに置き換わると、ハイライトは消えます。溶岩と水でできた黒曜石のようにハイライトすべきブロックが現れたときも、即時にハイライトされます。落下ブロックの連続も、そのブロックが壊されたときや、落ちてきた砂・砂利が着地したときに同じように更新されます。遠くにいて見えていない間に変わった部分が反映されるのは、近づいてチャンクが読み込まれたときです。

## 設定

`/peri config` で設定画面を開けます。Mod Menu が入っていれば、Mod Menu の PeriScan の設定ボタンからも開けます。設定は保存するとすぐに反映され、スキャン中なら新しい設定でスキャンし直します。

### 全般

| 項目 | 内容 | 初期値 |
|---|---|---|
| 南北トレンチの幅 | 北端と南端のトレンチの幅（列数、3 〜 32） | 12 |
| 東西トレンチの幅 | 東端と西端のトレンチの幅（列数、3 〜 32） | 3 |
| スキャンする最大Y | スキャンを実行するときの Y 座標の最大値です | 128 |
| ハイライトを表示 | オフにすると、PeriScan が描くもの（ハイライトと未スキャンチャンクの箱）をすべて非表示にします。スキャンは続きます | オン |
| 未スキャンチャンクをハイライト | まだスキャンしていないチャンクを箱で表示します | オン |
| 未スキャンチャンクの色 | 上記の箱の色 | オレンジ |
| 押すと壊れるブロックを水没判定から除外 | 葉・サンゴ・鍾乳石など、ピストンで押すと壊れるブロックは、水没していてもハイライトの対象外です | オン |
| 水没判定のブラックリスト | 水没していてもハイライトしないブロック | なし |

### ゾーンごとの設定

「トレンチの一ブロック外側」「トレンチの内側」「トレンチの底」「イーター領域」のそれぞれに、次の設定があります。

| 項目 | 内容 |
|---|---|
| このゾーンを走査する | オフにすると、そのゾーンはスキャンしません。すべてオフにするとスキャンは実行されません |
| このゾーンを表示 | オフにすると、そのゾーンのハイライトを隠します。スキャンは続きます |
| ハイライト色 | ハイライトの色（初期値はすべて白） |
| 水没ブロックを含める | 水没したブロック（水の入った階段など）もハイライトします |
| ハイライトするブロック | ハイライトするブロックのリスト（「トレンチの底」にはありません） |

ゾーン固有の設定は次のとおりです。

- **トレンチの内側**
  - 落下ブロックの連続数しきい値（2 〜 64、初期値 10）
  - state 変化ブロック（特定レーンのみ）: 2, 5, 8, 11 … 列目にあるときだけハイライトするブロックのリスト
- **イーター領域**
  - トレンチ範囲を含める: オンにすると、イーター領域がトレンチを含めた範囲全体になります（初期値オフ）

### ブロックの指定方法

ブロックのリストには、次のどれかを 1 行に 1 つずつ書きます。

- ブロック ID: `minecraft:obsidian`
- ブロックタグ（先頭に `#`）: `#minecraft:walls`
- PeriScan の特別な指定（下の表）

| 特殊なタグ | 一致するブロック |
|---|---|
| `#periscan:immovable` | ピストンで押せないブロック全般（岩盤を除く） |
| `#periscan:connecting` | 塀・フェンス・板ガラス・鉄格子など、隣のブロックとつながって形が変わるブロック |
| `#periscan:redstone_reactive` | ドア・トラップドア・フェンスゲート・銅の電球・ピストン・レッドストーンダスト/トーチ/ランプ・ディスペンサー・ホッパーなど、レッドストーン信号を受けて状態が変わるブロック（ボタンやレバーなど信号を出すだけのブロックは含まれない） |

入力中にブロック ID とタグの候補が表示されます。ワールドのタグが候補に出るのは、ワールドに入っている間に設定画面を開いたときだけです。候補にないものも入力できます。

存在しない ID など、書き間違えた項目は無視されます。存在しない項目一覧が画面右上に表示され、スキャンを始めたときにチャットで「不正な config エントリを無視しました」と警告されます。

## キー

「設定 → 操作設定 → キー割り当て」の PeriScan カテゴリに、次のキーが追加されます。最初はどれもキーが割り当てられていないので、使いたいものに割り当ててください。

| キー | 内容 |
|---|---|
| 設定を開く | 設定画面を開きます（`/peri config` と同じ） |
| ハイライトの表示切替 | PeriScan が描くものをすべて隠す／表示します。設定の「ハイライトを表示」と同じです |
| 再スキャン | `/peri scan reload` と同じ |
| スキャンを消去 | `/peri scan clear` と同じ |
| 「トレンチの一ブロック外側」の表示切替 | そのゾーンのハイライトを隠す／表示します。設定の「このゾーンを表示」と同じです |
| 「トレンチの内側」の表示切替 | 同上。落下ブロックの連続も一緒に隠れます |
| 「トレンチの底」の表示切替 | 同上 |
| 「イーター領域」の表示切替 | 同上 |

- 非表示にしてもスキャンは止まらないので、表示に戻したときには最新の状態になっています。
- 非表示の状態はゲームを再起動しても残ります。表示に戻すまで隠れたままです。
- 「このゾーンを走査する」がオフのゾーンにはハイライトするものがないので、キーを押しても「有効になっていません」と表示されるだけです。

## 設計図の一括配置

露天掘りを作るときは、毎回同じ設計図を同じ位置関係で置くことになります。設計図プロファイルに「どの設計図をどこに置くか」を登録しておくと、`/peri schematic place` でプロファイルの範囲に合わせて Litematica でまとめて配置できます。

この機能には Litematica が必要です。入っていなくても、ほかの機能は使えます。

設計図プロファイルは、`/peri add` で作るプロファイルと違い、すべてのワールド・サーバーで共通です。

### 設計図プロファイルの作りかた

1. 設定画面を開きます。名前は自由に付けることができます。新しく作成するときは、create コマンドを使用してください。
   ```
   /peri schematic edit <設計図プロファイル>
   または
   /peri schematic create <設計図プロファイル>
   ```
2. 「設計図を取り込む」に、使うファイルを追加します。候補には Litematica の設計図フォルダ（通常は `.minecraft/schematics`）にある `.litematic` ファイルが出ます。文字を入力すると候補が絞り込まれるので、クリックして選んでください。
3. 「変更を保存」を押します。取り込んだ設計図ごとに設定欄が現れます。
4. それぞれの設定欄で、設置する角と原点の高さを選び、もう一度保存します。

- ファイルは `config/periscan/schematics/<設計図プロファイル>/` に**コピー**されます。取り込んだ後は、元のファイルを移動・改名・削除しても構いません。
- 元のファイルを作り直しても、自動では反映されません。もう一度取り込んでください。同じ名前のファイルはコピーだけが置き換わり、設定は残ります。
- 同じ名前のファイルは、別のフォルダにあっても 1 回の保存では取り込めません。どれも取り込まれず、メッセージに一覧が出ます。片方の名前を変えるか、1 つずつ保存して取り込んでください（後から取り込んだほうで置き換わります）。
- 一番上の「origin の Y の初期値」は、新しく取り込む設計図が最初に持つ原点の高さです。取り込む前に設定してください（ネザー用のプロファイルなら 5 など）。
- 設計図をプロファイルから外すには、設定欄の「プロファイルから外す」をオンにして保存します。コピーも削除されます。

オーバーワールド用のプロファイルからネザー用を作るときのように、改変が少しで済むものを作りたい場合は、`/peri schematic copy <元> <新>` で複製してから、高さや角を変えてください。

### 設計図の保存のしかた

どのファイルも、次のルールで保存してください。

- 原点を、露天掘りの**北西の角のブロック**に合わせる
- 中身は、原点から東（+X）と南（+Z）の方向へ広がる形にする

複数の辺で使い回せる部分は 1 つだけ保存し、複数の角に設置します。

### 配置のされかた

角は X 側と Z 側の符号で表します。`+-` は +X/-Z の角です。

| 角 | 置かれる場所 |
|---|---|
| `--` | 北西の角に、保存したとおり |
| `+-` | 北東の角に、東西反転 |
| `-+` | 南西の角に、南北反転 |
| `++` | 南東の角に、180° 回転 |

- 原点の高さは設計図ごとに設定できます。新しく取り込んだ設計図の原点の高さは、プロファイルの「origin の Y の初期値」になります（既定値は -59 です）。
- 角を 1 つも選んでいない設計図は配置されません。
- 反転すると回路の左右も入れ替わります。左右対称でない回路は、反転すると動かないことがあります。
- 180° 回転すると装置の向きが逆になります。
- オプションで、配置するときに回転、反転をしないようにできます。

### 配置されたもの

- Litematica の配置一覧に `peri/<プロファイル名>/…` という名前で追加されます。誤って動かさないよう、位置はロックされています。
- 同じプロファイルでもう一度実行すると、前に配置したものは置き換えられます。
- 読み込めないファイルが 1 つでもあると、何も配置されません。
- `/peri schematic clear <名前>` で、プロファイルの配置を消せます。`/peri remove` でプロファイルを削除したときも消えます。
- 配置は設計図プロファイル内のコピーを参照し続けます。設計図を外したり設計図プロファイルを削除したりすると、ほかのワールドでそこから作った配置は読み込めなくなります。

## 困ったとき

| 表示・症状 | 対処 |
|---|---|
| 「すべてのゾーンが無効です」 | `/peri config` で、少なくとも 1 つのゾーンの「このゾーンを走査する」をオンにしてください |
| 「profile「…」は … のprofileです」 | プロファイルを作ったディメンションに移動してから実行してください |
| 「未ロードチャンクが N 個あります」 | オレンジの箱の場所に近づくと、そのチャンクがスキャンされます |
| 「保存されたprofileがあります」 | そのディメンションで `/peri scan reload` を実行すると、スキャンを再開します |
| 「litematicaが入っていない(または非対応バージョンの)ため…」 | Litematica を入れるか、Minecraft のバージョンに合った Litematica に更新してください |
| 「設計図プロファイル「…」はありません」 | `/peri schematic create <設計図プロファイル>` で作るか、`/peri schematic list` で名前を確認してください |
| 「… には設置するものがありません」 | `/peri schematic (edit\|create) <設計図プロファイル>` で設計図を取り込み、角を 1 つ以上選んでください |
| 「取り込みに失敗」 | ファイルが Litematica の設計図フォルダにあり、名前が `.litematic` で終わっているか確認してください |
| 「… の読み込みに失敗しました」 | そのファイルが破損していないか、Litematica で開けるか確認してください |
| スキャン中なのにハイライトが出ない | 設定の全般の「ハイライトを表示」と、各ゾーンの「このゾーンを表示」を確認してください。キーでオフにしたままの可能性があります |
| ゾーンのキーを押すと「…は有効になっていません」 | 設定で、そのゾーンの「このゾーンを走査する」をオンにしてください |
| シェーダー使用中にハイライトが見えない | Iris を最新版に更新してください |
